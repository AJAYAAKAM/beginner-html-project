🔐 Login Page

A simple and responsive Login Page built using HTML and CSS. This project demonstrates basic web design concepts such as form inputs, buttons, hover effects, focus states, gradients, and responsive layout.

🚀 Features

- Clean and modern login interface
- Username input field
- Password input field
- Login button with hover effect
- Forgot Password link
- Input focus effect
- Gradient background
- Responsive and centered layout
- Simple and beginner-friendly design

🛠️ Technologies Used

- HTML5 – Structure of the webpage
- CSS3 – Styling, layout, colors, effects, and responsiveness
